# 中医学问答 · 学科体系与用法（qa-theory）

> 本文件是「中医学问答速查」技能的**总论与索引地图**。内容依据杨医亚主编《中医学问答》（上册、下册）的结构整理——这是一部**问答体**的中医全科参考书，上下两册、十四部分、千余问，覆盖从基础理论到临床各科。
> 本技能的分工：self-study-tcm 给「学医路径」，tcm-syndrome-lookup 给「证候辨证」，本技能 tcm-wenda 给「知识点问答」——你脑子里冒出一个具体问题，就来这里查。

## 一、这套书为什么适合做成"速查工具"

- **问答体天然贴合求助句式**：读者问的本来就是"什么是命门""风寒和风热怎么区别"，与技能对话的提问方式完全一致。
- **检索友好、颗粒度细**：一个问题一答，最短几行、最长数百字，随用随查，不用从头读。
- **覆盖全科、权威系统**：从阴阳五行到针灸伤科，14 个部分构成一张完整的中医知识网，适合自学、备考、临床备查。

## 三、怎么用本技能（路由逻辑）

当你抛出一个具体问题时，按下面规则落点：

1. **问"某个概念/理论是什么"** → 第一部分 总论（如"命门是什么""痰饮怎么形成""瘀血有什么特点"）。
2. **问"某部经典怎么读/某经怎么辨"** → 第二~五部分（内经 / 伤寒 / 金匮 / 温病）。
3. **问"某味药/某类药性"或"某方怎么用"** → 第六、七部分（中药 / 方剂）。
4. **问"某病怎么回事、怎么辨证治"** → 第八~十三部分（按科别：内科/妇科/儿科/外科/伤科/五官科）。
5. **问"针灸/穴位/手法"** → 第十四部分 针灸。
6. **不确定问什么、想系统过一遍** → 调 `scripts/build_qa_guide.py` 生成《中医学问答索引手册》（A4，可存 PDF）。

## 四、与另外两套技能的关系（避免重复、各司其职）

- **self-study-tcm（自学中医阶梯）**：回答"我该按什么顺序学、每阶段读什么书"——**路径层**。
- **tcm-syndrome-lookup（证候学速查）**：回答"这个证由哪些候组成、证→候→方症怎么拆"——**证候/辨证层**。
- **tcm-wenda（本技能，中医学问答）**：回答"XX 概念到底是什么意思、XX 问题书里怎么答"——**知识点问答层**。

三者互补：用路径定方向，用问答补概念，用证候做临床辨证拆解。

## 五、内容使用原则（重要）

- 本技能所有问答**只列"常"（标准答案要点）**，复杂个案、兼夹变证请遵医嘱。
- 古籍方剂、针灸操作**严禁自行照用**；所有内容用于理解与学习，不替代执业医师诊疗。详见 `disclaimer.md`。
