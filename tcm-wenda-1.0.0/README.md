# 中医学问答速查（tcm-wenda）使用说明

> 一套基于杨医亚主编《中医学问答》（上/下册）的**中医全科问答速查 + 分步陪学**技能。
> 带着具体问题来，带着答案走；想系统学，就按六阶一步步来。

## 一、解决什么（为什么值得收藏）

市面上的中医内容大多"讲一遍就走"——读完即忘、毫无回头价值（矩阵里同类技能 500+ 下载却 0 收藏就是教训）。
本技能反其道而行，做成三件让人**反复回来**的事：

1. **随身问答字典**：千余问里挑出高频易混点做成速查卡，遇疑即查、查完即走、下次还来。
2. **可下载索引手册**：`build_qa_guide.py` 一键出 A4《中医学问答索引手册》，打印贴墙/存手机，边学边打勾。
3. **六阶分步陪学**：每次只给一阶，过关才推进——制造"下次再来"的回访理由。

它和矩阵内另两套互补：**自学阶梯**给路径、**证候学速查**给辨证、**本技能**给知识点问答。

## 三、怎么用（双模式）

- **模式 A · 分步陪学（主）**：问"我零基础怎么开始""下一阶学什么" → 按 `learning-progression.md` 给当前阶内容与自测，过关再推进。
- **模式 B · 一次性全景**：问"帮我生成索引手册" → 直接出 A4，先通览再细学。

直接问它：「什么是命门」「风寒和风热感冒怎么区别」「君臣佐使是什么」
「伤寒六经辨证是什么」「内科咳嗽怎么辨」「帮我生成我的问答索引手册」即可。

## 六、FAQ

- **Q：这和另外两套中医技能重复吗？** 不重复。路径（学什么顺序）/ 证候（怎么辨证）/ 问答（概念是什么）三层面互补。
- **Q：内容靠谱吗？** 结构全部依据杨医亚《中医学问答》原书 14 部分；卡片要点为中医通行共识，原书千余问为完整底本。
- **Q：能给我开药/扎针吗？** 不能。本技能是学习与参考工具，方剂针灸严禁自服自施，详见 `disclaimer.md`。

## 七、边界

本技能是**自学辅导与知识检索工具**，不是诊疗工具，不替代执业医师。所有问答仅供理解中医
思路、辅助学习，身体不适务必就医。古籍方剂、针灸操作严禁自行使用。
