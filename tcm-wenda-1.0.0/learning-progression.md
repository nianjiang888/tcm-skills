# 中医学问答 · 六阶分步陪学（learning-progression）

> 本文件是技能的**主引擎**。对应你之前提的关键问题——"学多深、下一步学什么、学到什么程度"——这里把《中医学问答》的 14 部分拆成 **6 个阶段**，每阶明确：**学什么 / 学多深（掌握标准）/ 自测 / 时长 / 完成标志 / 下一阶 / 常见误区**。
>
> **双模式（想清楚了）：**
> - **分步陪学（主模式）**：每次只给当前一阶的内容与自测，过关才推进下一阶——制造"下次再来"的回访理由，破解"看完就走、0 收藏"陷阱（对标矩阵里 tcm-diagnostic-thinking 525 下载/0 收藏的教训）。
> - **一次性全景（交付物）**：`scripts/build_qa_guide.py` 直接出《中医学问答索引手册》A4（可存 PDF），适合想先通览再细学的人。

## 第一阶 · 总论筑基（对应第一部分）

- **学什么**：阴阳五行、藏象（五脏六腑奇恒之府）、气血津液、经络、病因病机。
- **学多深**：能口头讲清"阴阳关系""五脏核心功能""气/血/津液关系""六淫各自性质""痰饮瘀血概念"。不要求背经络全部循行，但要懂经络的临床意义。
- **自测（打勾）**：
  - ☑ 能说出肾藏精、命门火、脾胃后天之本的含义（见 qa-cards A-1/A-2/A-3）
  - ☑ 能区分内风与外风、痰饮与瘀血（A-4/A-5/A-6）
  - ☑ 能解释"正气存内邪不可干"（A-7）
- **时长**：零基础约 3–4 周（每天 1 小时）。
- **完成标志**：翻开任一总论问题能答出要点，不混淆基本概念。
- **下一阶**：进入经典四门（第二~五部分）。
- **误区**：急于啃《内经》原文而概念未立 → 多半事倍功半。

## 第二阶 · 经典四门（对应第二~五部分：内经/伤寒/金匮/温病）

- **学什么**：《内经》要旨、《伤寒论》六经、《金匮要略》脏腑杂病、《温病学》卫气营血与三焦。
- **学多深**：伤寒能画六经传变框架、说清太阳病主证；温病能区分卫气营血层次与三焦部位（B-1/B-2）；金匮懂"脏腑辨证+方证对应"（B-3）。
- **自测**：
  - ☑ 能用一句话说明六经辨证的实质
  - ☑ 能说清温病"卫气营血"与"三焦"的关系
  - ☑ 能说出金匮"见肝之病当先实脾"的防变思想
- **时长**：4–6 周。
- **完成标志**：四部经典各能举一例说明其辨证主线。
- **下一阶**：方药基础。
- **误区**：四部经典齐头并进、贪多 → 建议先伤寒或内经一门深入。

## 第三阶 · 方药基础（对应第六、七部分：中药/方剂）

- **学什么**：药性（四气五味、升降浮沉、归经、配伍禁忌）、方剂（君臣佐使、类方鉴别、常用经方方义）。
- **学多深**：掌握 50–80 味常用药性味归经；背熟 30–50 首基础方组成与主治；理解君臣佐使结构（C-1/C-2/C-3）。
- **自测**：
  - ☑ 能解释四气五味并能举例
  - ☑ 能默画一味方剂的君/臣/佐/使
  - ☑ 能区分经方与时方
- **时长**：4–5 周。
- **完成标志**：给一个证候能联想 2–3 首候选方并说清差异。
- **下一阶**：内科精读（最大部分）。
- **误区**：只背方歌不求方义 → 遇变证不会化裁。

## 第四阶 · 内科精读（对应第八部分，全书最常用）

- **学什么**：感冒、咳嗽、胃脘痛、泄泻、水肿、黄疸、心悸、眩晕、痹症等内科常见病，每病"病因—辨证—治法—代表方"。
- **学多深**：掌握每病 3–5 个基本证型与通治思路；重点吃透风寒/风热、外感/内伤、实喘/虚喘、暴泻/久泻等鉴别（D-1~D-4）。
- **自测**：
  - ☑ 风寒 vs 风热感冒治法区别（D-1）
  - ☑ 外感 vs 内伤咳嗽辨别（D-2）
  - ☑ 实喘 vs 虚喘鉴别（D-3）
  - ☑ 泄泻各型治要（D-4）
- **时长**：6–8 周（可长期备查）。
- **完成标志**：内科常见病能说出"辨什么、怎么治"的框架。
- **下一阶**：妇儿外五官伤科。
- **误区**：只记方不记"辨"，临床一对不上就乱。

## 第五阶 · 妇儿外五官伤科（对应第九~十三部分）

- **学什么**：妇科经带胎产、儿科稚阴稚阳、外科痈疽疔疮、伤科手法、五官科病证。
- **学多深**：按方向选学——妇科必懂"经带胎产"四纲与冲任肝脾肾病机（D-5）；儿科必懂"易虚易实、用药轻清"（D-6）；其余方向各取所需。
- **自测**：
  - ☑ 妇科四纲与调冲任总则（D-5）
  - ☑ 儿科稚阴稚阳与用药原则（D-6）
- **时长**：3–5 周（按方向取舍）。
- **完成标志**：所选方向能独立完成基础问答检索。
- **下一阶**：针灸与综合运用。
- **误区**：非专科硬通读全部 → 建议"主攻一门+其余备查"。

## 第六阶 · 针灸与综合运用（对应第十四部分 + 跨科能力）

- **学什么**：经络腧穴总览、刺灸法、配穴思路；以及把前 5 阶串起来的"跨科检索能力"。
- **学多深**：懂十四经要穴定位规律、常用配穴法；遇到任意问题能 5 秒内判断它落在 14 部分哪一格（用 qa-theory.md 路由）。
- **自测**：
  - ☑ 给任意中医问题能说出"去第几部分查"
  - ☑ 能描述针灸基本治则与 2–3 个常用配穴法
- **时长**：持续（工具化阶段）。
- **完成标志**：本技能成为你的"随身中医问答字典"——遇疑即查、查完即走、下次还来。
- **误区**：以为学到这阶就"能治病" → 技能是学习与参考工具，临床必须跟师与执业医师把关。
