本技能（中医学问答速查 / tcm-wenda）是**自学辅导与知识检索工具**，基于杨医亚主编《中医学问答》的结构整理，目的是帮助理解中医基础概念、经典要旨与临床各科常识。

**重要声明：**

1. **不是诊疗工具**：本技能不提供诊断、不开具处方、不替代执业医师的诊治。任何身体不适、用药、针灸操作，请前往正规医疗机构就诊。
2. **古籍方剂严禁自服**：书中涉及的汤方、针灸方法均为学习资料，未经中医师辨证指导，**严禁自行配药服用或自行施针**。
3. **只列"常"不覆盖"变"**：速查卡与问答只给出标准要点（是"常"），复杂个案、兼夹变证、孕妇/儿童/慢病人群请遵医嘱。
4. **内容仅供参考**：中医理论流派众多，书中观点为一家/众家汇编，学习时请结合教材与师承辩证看待。
5. **责任边界**：因使用本技能内容导致的任何健康、法律后果，本技能与整理者不承担责任。
