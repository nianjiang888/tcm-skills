# 中医学问答速查（tcm-wenda）

## 解决什么

把杨医亚主编《中医学问答》（上/下册，14 部分、千余问）整理成**「带着具体问题来查」的中医全科问答速查工具**——你脑子里冒出"什么是命门""风寒和风热怎么区别""君臣佐使是什么"，就来解决。

本技能与矩阵内另两套互补：
- `self-study-tcm`（自学中医阶梯）= **路径层**：我该按什么顺序学。
- `tcm-syndrome-lookup`（证候学速查）= **证候层**：这个证怎么拆、证→候→方症。
- 本技能 `tcm-wenda` = **知识点问答层**：某个概念/某本书/某病，书里怎么答。

## 怎么用（交互方式 · 路由表）

| 用户意图 | 路由 |
|---|---|
| 「什么是命门/肾藏精/痰饮/瘀血」「六淫是什么」 | `qa-theory.md` + `qa-cards.md`（A 类基础卡） |
| 「内经/伤寒/金匮/温病怎么读、怎么辨」 | `qa-cards.md`（B 类经典卡） |
| 「四气五味/君臣佐使/经方时方」 | `qa-cards.md`（C 类方药卡） |
| 「感冒/咳嗽/喘/泄泻/妇科/儿科怎么辨怎么治」 | `qa-cards.md`（D 类临床卡） |
| 「我学到哪了 / 下一步学什么 / 每阶段学多深」 | `learning-progression.md` |
| 「帮我生成我的中医问答索引手册」 | 调 `scripts/build_qa_guide.py` 出 A4 HTML |

## 判定 / 路由逻辑（三条要点）

1. **先定位"落在 14 部分哪一格"**：任何问题先判断属于总论/经典/方药/临床哪一科（见 `qa-theory.md` 路由），再深挖，避免答非所问。
2. **只答"常"，不替"变"做主**：速查卡只列标准要点（是常），复杂个案、兼夹变证、特殊人群一律提示「遵医嘱」，不擅自给诊疗结论。
3. **问答体即检索体**：用户提问句式与书中问答天然一致，直接以"问题→要点→辨析"卡片作答，比长篇讲义更易收藏复用。

## 交付物

`scripts/build_qa_guide.py` 按 `--level`(入门/备考/临床) 与 `--focus`(全科/某科) 生成
《中医学问答索引手册》A4 HTML（十四部分导览 + 高频问答入口 + 六阶路线 + 个人勾选框），
浏览器打印即 PDF。这是「让人收藏」的核心载体。

## 参考文档（内置离线知识库，无联网依赖）

- `qa-theory.md` —— 14 部分导览 + 用法路由 + 与另两套技能的关系
- `qa-cards.md` —— 高频易混问答速查卡（A 基础/B 经典/C 方药/D 临床）
- `learning-progression.md` —— 六阶分步陪学（每阶 学什么/学多深/自测/时长/完成标志/误区）
- `disclaimer.md` —— 教育参考非诊疗、古籍方剂严禁自服

## 边界

本技能是**自学辅导与知识检索工具**，不是诊疗工具，不替代执业医师。所有问答仅供理解中医
思路、辅助学习，身体不适务必就医。详见 `disclaimer.md`。
