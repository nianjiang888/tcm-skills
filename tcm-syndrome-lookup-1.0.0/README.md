# 中医证候学速查（tcm-syndrome-lookup）使用说明

## 它解决什么（为什么值得收藏）

学中医辨证，最大的坑是「背了一堆证名，遇到真实病人就乱」。《中医证候学》（李洪成等，2007）的
独特价值，是把「证」往下拆成可识别、可方药对应的 **「候」**，建立 **证 → 候 → 方症** 三级体系，
并以病因为纲分 **12 门**、脏腑为目分 **45 类、281 证、1870 候、7000 余方症**。

本技能把这套「巨著级」框架，做成两样**会反复回来用**的东西：

1. **证候速查卡**（随时回来翻的查阅区）——12 门 + 脏腑各论的代表证候，统一格式：
   归属编码 / 临床表现 / 辨证要点 / 治法 / 代表方 / 鉴别 / 调护。
2. **可下载的《中医证候检索手册》**（存下来、转发的个人交付物）——A4 HTML，浏览器打印即 PDF。

对照矩阵里 `tcm-diagnostic-thinking`（中医诊断）525 下载 / **0 收藏**的教训：
「讲一遍就走」的内容没人存。本技能反其道——做成**参考工具 + 个人化路线图**，复制
微短剧合规 A4 报告的高收藏套路；内容全部结构化自原书，未编造。

## 怎么用（两种模式，想清楚再选）

- **分步陪学（主推）**：每次只给当前一阶，自测过关才推进——制造「下次还回来」的理由。
  直接问：「我零基础怎么开始学证候学」「第 3 阶自测怎么过」。
- **一次性全景（交付物）**：`scripts/build_syndrome_manual.py` 出 A4 检索手册，可存可转发。

常用问法：「证候学是什么」「证和候有什么区别」「12 门是哪 12 门」「风证怎么辨」
「虚证怎么分气血阴阳」「心病有哪些证」「帮我生成我的证候检索手册」。

## 六阶总览

1. 总论筑基（三级体系 / 12门45类框架）
2. 病因证候（12 门逐门击破）
3. 病机基础（气血津液 / 脏腑 / 虚证细化）
4. 外感体系（六经 / 卫气营血 / 三焦）
5. 脏腑各论（45 类 281 证精读）
6. 综合临床与传变（方症对应 / 医案）

## 常见问题

- **和 `tcm-diagnostic-thinking` 有什么区别？** 那个是「诊断思维」一次性讲解；本技能是
  「证候分类检索 + 分步陪学 + 可下载手册」的参考工具，强调反复使用与收藏。
- **内容全吗？** 本技能提供框架 + 高价值代表条目（速查卡）；原书 1870 候为穷尽库，深度查阅请以原书为准。
- **能开药吗？** 不能。本技能非诊疗工具，方剂均为学术举例，须执业医师指导使用。

## 边界

本技能是学术研究与自学参考，不提供诊断、不开具处方、不替代执业医师。详见 `disclaimer.md`。
