# 中医证候速查卡（收藏主区）

> 按《中医证候学》「12 门 → 45 类 → 281 证 → 1870 候」框架抽取**高价值代表条目**。
> 每卡格式：**归属编码 / 临床表现（主·副·宾症）/ 辨证要点 / 治法 / 代表方 / 鉴别 / 调护**。
> 编码沿用原书 `L(门)Z(类)H(候)`；未标具体 H 码者为「证类」层级，供入门检索。
> ⚠️ 本卡为学习参考，不替代执业医师辨证与处方。详见 `disclaimer.md`。

## 一、病因 12 门 · 代表证候

### 1. 风证门（L01）— 卫气失宣候（L01-Z01-H001）
- **临床表现**：主症——恶风、喷嚏、鼻塞、清涕、脉浮；副症——头痛、身楚、微热；宾症——咽干、咳嗽。
- **辨证要点**：风性开泄，先犯肺卫；脉浮、恶风为先；与寒并见则身疼、无汗。
- **治法**：辛散风邪、宣通卫气（风寒加辛温，风热加辛凉）。
- **代表方**：风寒——荆防败毒散；风热——银翘散。
- **鉴别**：与「湿困清阳」区别在有无身重、苔腻；与「气虚卫外不固」区别在脉虚、易感反复。
- **调护**：避风保暖，汗出勿当风。

### 2. 寒证门（L02）— 清阳虚郁候
- **临床表现**：主症——畏寒、肢冷、舌淡、苔白；副症——蜷卧、口淡、小便清长。
- **辨证要点**：寒伤阳气，温煦失职；得温则减、遇寒加重为辨。
- **治法**：温阳散寒。
- **代表方**：轻——桂枝汤；重——附子理中汤、四逆汤（阳虚厥逆）。
- **鉴别**：实寒（有感寒史、痛剧拒按）vs 虚寒（久病、喜按、脉微）。
- **调护**：忌生冷，温覆。

### 3. 湿证门（L04）— 清阳不化候
- **临床表现**：主症——身重、脘痞、苔腻、脉濡；副症——纳呆、便溏、头重如裹。
- **辨证要点**：湿性重浊黏滞，易阻气机、碍清阳；病程缠绵。
- **治法**：化湿运脾、升清醒脾。
- **代表方**：平胃散、藿香正气散；湿热——茵陈蒿汤/三仁汤。
- **鉴别**：寒湿（苔白腻、不渴）vs 湿热（苔黄腻、口渴、尿赤）。
- **调护**：忌肥甘厚味、居处防潮。

### 4. 火（阳）证门（L06）— 清气郁蒸候
- **临床表现**：主症——发热、面赤、舌红、脉数；副症——口渴、汗出、心烦。
- **辨证要点**：火性炎上、耗津动血；实火（脉数有力、便秘）vs 虚火（脉细数、午后热）。
- **治法**：实火清泻，虚火滋阴降火。
- **代表方**：实火——黄连解毒汤；虚火——知柏地黄丸。
- **鉴别**：与「气郁化火」区别在有无情志诱因、胁胀。
- **调护**：忌辛辣燥热。

### 5. 气证门（L07）— 肝郁气滞（肝胃/肝脾类）
- **临床表现**：主症——情志抑郁、胁胀、善太息；副症——脘痞、纳差、月经不调。
- **辨证要点**：肝失疏泄，气机郁滞；与情绪密切相关，脉弦。
- **治法**：疏肝理气。
- **代表方**：柴胡疏肝散、逍遥散。
- **鉴别**：气郁（无形胀痛、攻窜）vs 血瘀（刺痛、固定、舌紫）。
- **调护**：调畅情志。

### 6. 痰证门（L08）— 痰热壅肺 / 风痰
- **临床表现**：主症——咳喘、痰黄稠或咯吐不畅、苔黄腻；风痰——眩晕、苔腻、脉弦滑。
- **辨证要点**：痰随气升降，无处不到；热痰黄稠、寒痰清稀。
- **治法**：清热化痰 / 祛风化痰。
- **代表方**：清金化痰汤；风痰——半夏白术天麻汤。
- **鉴别**：痰（咯吐可见、苔腻脉滑）vs 饮（停积、外形可见如胸水）。
- **调护**：忌滋腻生痰之品。

### 7. 瘀（血）证门（L10）— 心血瘀阻
- **临床表现**：主症——胸痹刺痛、固定不移、舌紫暗；副症——心悸、气短、唇青。
- **辨证要点**：血瘀络阻，不通则痛；痛处固定、舌有瘀点、脉涩。
- **治法**：活血化瘀、通络止痛。
- **代表方**：血府逐瘀汤、冠心 II 号方。
- **鉴别**：与「痰浊闭阻」区别在苔腻与否；与「气滞」区别在痛否固定。
- **调护**：避寒邪、勿过劳。

### 8. 虚证门（L12）— 气血阴阳虚（摘要）
| 虚类 | 主症 | 代表方 |
|---|---|---|
| 气虚 | 神疲、乏力、气短、自汗、舌淡、脉弱 | 四君子汤/补中益气汤 |
| 血虚 | 面白、心悸、爪甲淡、脉细 | 四物汤 |
| 阴虚 | 潮热、盗汗、舌红少苔、脉细数 | 六味地黄丸/左归丸 |
| 阳虚 | 畏寒、肢冷、舌淡胖、脉沉微 | 金匮肾气丸/右归丸 |
| 阳虚失固/失摄 | 滑脱不禁（汗、泄、遗、崩） | 固脱收涩（如牡蛎散、真人养脏汤） |
| 阳气虚脱 | 厥冷、脉微欲绝、大汗 | 参附汤/回阳救逆 |

## 二、脏腑各论 · 代表证类

### 心病证类
- **心气虚**：心悸、气短、乏力、舌淡、脉虚 → 补益心气（养心汤）。
- **心血虚**：心悸、失眠、健忘、面白 → 养血安神（归脾汤）。
- **心阴虚**：心悸、心烦、盗汗、舌红少津 → 滋阴养心（天王补心丹）。
- **心火亢**：口舌生疮、心烦、舌红 → 清心泻火（导赤散）。
- **心阳虚**：心悸、畏寒、胸闷、肢冷 → 温通心阳（桂枝甘草汤/参附）。

### 肝病证类
- **肝气郁结**：胁胀、抑郁、脉弦 → 疏肝（柴胡疏肝散）。
- **肝阳上亢**：头晕、面红、急躁、脉弦劲 → 平肝潜阳（天麻钩藤饮）。
- **肝风内动**：抽搐、眩晕、肢麻 → 息风（羚角钩藤汤/镇肝熄风汤）。
- **肝血虚**：目涩、肢麻、月经少 → 补肝血（四物汤加味）。

### 脾病证类
- **脾气虚**：纳呆、便溏、肢倦、舌淡胖 → 健脾（四君子/参苓白术）。
- **脾阳虚**：腹痛喜温、泄泻清冷 → 温中（理中汤）。
- **脾虚湿困**：身重、苔腻、脘痞 → 化湿健脾（平胃+四君）。

### 肺病证类
- **肺气虚**：短气、易感、自汗 → 补肺（玉屏风散/补肺汤）。
- **肺阴虚**：干咳、痰少、潮热 → 润肺（沙参麦冬汤/百合固金汤）。

### 肾病证类
- **肾阴虚**：腰膝酸软、盗汗、遗精、舌红少苔 → 滋肾（六味/左归）。
- **肾阳虚**：腰膝冷痛、畏寒、阳痿/宫冷、夜尿 → 温肾（金匮肾气/右归）。
- **肾气不固**：遗精、滑胎、小便频数 → 固肾（桑螵蛸散/缩泉丸）。

### 胃病证类
- **胃阴虚**：饥不欲食、干呕、口干 → 养胃阴（益胃汤/沙参麦冬）。
- **胃气上逆**：恶心、呕吐、呃逆 → 降逆（半夏泻心/旋覆代赭）。

## 三、使用提示
- 先定**门**（病因），再定**类**（脏腑），最后落到**候/证**与**方症**。
- 复合病机（如「肝郁脾虚」「脾肾阳虚」）多为多类兼病，需合参。
- 完整 1870 候检索，请以原书《中医证候学》为准；本卡为高频代表，利于起步与速查。
