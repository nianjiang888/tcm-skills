# 中医证候学速查

把《中医证候学》（李洪成、李新平、李新晔 编著，中国医药科技出版社 2007）整理成
**「会反复回来查的证候参考工具 + 可下载的《中医证候检索手册》」**——
全书以病因为纲分 **12 门**，以脏腑为目分 **45 类、281 证、1870 候、7000 余方症**，
建立「证 → 候 → 方症」三级诊断体系。本技能不替代原著，而把这套框架与高价值代表条目
做成便于检索、便于分步学习的工具。

## 解决什么

- 想系统学「辨证」却卡在「证名一大堆、遇变证就乱」——本技能先讲清**三级体系**，再分步陪学。
- 临床/学习中遇到症状群，要快速判断「归哪一门、属哪一类、是什么候」——`syndrome-cards.md` 速查。
- 需要一份**能存下来、能转发**的个人化检索手册——`scripts/build_syndrome_manual.py` 生成 A4。

## 判定 / 路由逻辑（三条要点）

1. **先门后类，再落候证**：任何症状群先判病因（门），再定脏腑（类），最后到候/证与方症。
   跳过这一步直接背证名，是「遇变证必乱」的根因。
2. **证是静的、候是动的**：`证=病位+病因`（标志性），`候=复合病机`（机制性，含主/副/宾症）。
   即使用户主诉未出现某主症，只要单位病机形成即可据此立法——这是「治病求本」的操作基础。
3. **知常达变，复合合参**：速查卡只列高频「常」；真实病案多为多类兼病
   （肝郁脾虚、脾肾阳虚），须合参，复杂个案遵医嘱。

## 交付物

`scripts/build_syndrome_manual.py` 按 **专长领域（全科/内科/妇科/儿科/外感温病）× 学习层次（入门/进阶/临床）**
生成《中医证候检索手册》：含 12 门索引、六阶路线、个人进度自查、辨证入口速记，输出 A4 HTML（可另存 PDF）。
这是本技能「让人收藏」的核心载体——可存、可转发、每次回来都能用。
