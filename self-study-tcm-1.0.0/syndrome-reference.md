# 常见病辨证速查（收藏主区）

> 统一格式：**辨证要点 → 证型（主症 / 治法 / 代表方） → 鉴别诊断 → 兼夹变证 → 调护**。
> ⚠️ 本表只列"常"（基本证型、通治方）。**仅供理解中医思路、辅助学习，严禁照搬自服；身体不适应及时就医**（见 `disclaimer.md`）。

---

## 感冒
- **辨证要点**：先分风寒/风热/暑湿；再辨虚人（气虚/阳虚/阴虚）兼感；看恶寒发热孰重、汗否、咽舌脉。
- **证型**
  - 风寒：恶寒重发热轻、无汗、喷嚏清涕、苔薄白、脉浮紧 → 辛温解表 → 荆防败毒散 / 麻黄汤类。
  - 风热：发热重恶寒轻、咽痛、黄涕、舌尖红苔薄黄、脉浮数 → 辛凉解表 → 银翘散 / 桑菊饮。
  - 暑湿（夏）：身热不扬、头重胸闷、呕恶、苔腻 → 清暑祛湿 → 新加香薷饮。
  - 虚人兼感：平时易感冒、乏力气短 → 益气解表 → 参苏饮；阳虚加再造散；阴虚加减葳蕤汤。
- **鉴别**：风寒 vs 风热看"寒热轻重+咽痒痛+涕痰色+舌脉"；感冒 vs 温病初起（温病传变快、易入营血）。
- **兼夹变证**：风寒化热、挟痰（咳嗽）、挟食（腹胀）。反复感冒提示正虚，转第五阶"虚人"思路。
- **调护**：避风保暖、多饮温水、清淡食；虚人平时练"扶正"（玉屏风散类需医师定）。

## 咳嗽
- **辨证要点**：辨外感/内伤；外感分风寒（咳白稀痰、恶寒）、风热（痰黄稠、咽痛）、风燥（干咳少痰、咽干）；内伤分痰湿、痰热、肝火、阴虚。
- **证型**
  - 外感风寒：三拗汤 / 止嗽散。
  - 外感风热：桑菊饮。
  - 风燥伤肺：桑杏汤。
  - 内伤痰湿：二陈汤 + 三子养亲汤（本在脾，健脾化痰）。
  - 内伤痰热：清金化痰汤。
  - 肝火犯肺：黛蛤散 + 泻白散。
  - 肺阴亏耗：沙参麦冬汤。
- **鉴别**：**外感咳嗽起病急、伴表证；内伤咳嗽反复、本在脏腑（尤脾）**。久咳必查内伤。
- **兼夹变证**：外感久不愈转内伤；痰瘀互结。
- **调护**：忌生冷辛辣肥甘；脾为生痰之源，平时顾脾。

## 心悸（心慌）
- **辨证要点**：虚（气血阴阳亏虚）为主，兼痰火、水饮、瘀血。看伴症：气短乏力（心气虚）、头晕舌淡（血虚）、心烦盗汗（阴虚）、畏寒肢冷（阳虚）。
- **证型**：心虚胆怯（安神定志丸）、心血不足（归脾汤）、阴虚火旺（天王补心丹/黄连阿胶）、心阳不振（桂枝甘草龙骨牡蛎汤）、水饮凌心（苓桂术甘汤）、瘀阻心脉（桃仁红花煎）。
- **鉴别**：生理性（惊吓、咖啡）一过性 vs 病理性持续；须排除心律失常常规就医。
- **调护**：调情志、避浓茶咖啡、规律作息。

## 胃痛（胃脘痛）
- **辨证要点**：辨寒热虚实气血。喜温按（寒/虚）、拒按灼痛（热/实）；胀痛属气、刺痛属血。
- **证型**：寒邪客胃（良附丸）、饮食停滞（保和丸）、肝气犯胃（柴胡疏肝散）、肝胃郁热（化肝煎）、脾胃虚寒（黄芪建中汤）、胃阴亏虚（一贯煎+芍药甘草）。
- **鉴别**：胃痛 vs 真心痛（胸痛彻背、危候，立即就医）；vs 胁痛（部位在肋）。
- **兼夹变证**：久痛入络（化瘀）、反复转虚（健脾）。
- **调护**：饮食有节、忌生冷辛辣、情志舒畅。

## 眩晕
- **辨证要点**：辨虚实。实：肝阳（头胀痛、面红脉弦）、痰浊（头重如裹、苔腻）、瘀血；虚：气血虚（乏力舌淡）、肾精亏（腰酸耳鸣）。
- **证型**：肝阳上亢（天麻钩藤饮）、气血两虚（归脾汤）、肾精不足（左归丸）、痰浊中阻（半夏白术天麻汤）、瘀血阻窍（通窍活血汤）。
- **鉴别**：眩晕 vs 中风先兆（肢麻语謇须警惕）；vs 贫血/低血压（西医排查）。
- **调护**：低盐、忌暴怒、起身缓防跌。

## 痹症（关节疼痛）
- **辨证要点**：辨行/痛/着/热痹。风邪盛（游走）——行痹；寒邪盛（冷痛）——痛痹；湿邪盛（重着）——着痹；热邪（红肿热）——热痹。
- **证型**：行痹（防风汤）、痛痹（乌头汤）、着痹（薏苡仁汤）、热痹（白虎加桂枝汤）。
- **鉴别**：痹 vs 痿（痿不痛、痹痛）；风湿/类风湿/痛风西医鉴别。
- **兼夹变证**：久痹肝肾亏虚（独活寄生汤）、痰瘀阻络。
- **调护**：避寒湿、保暖、适度活动。

## 水肿
- **辨证要点**：**腰以上肿（风水，属肺）发汗；腰以下肿（属脾肾）利小便**——"开鬼门、洁净府"。辨阳水（实、起病急、红赤）、阴水（虚、起病缓、苍白）。
- **证型**：风水相搏（越婢加术汤）、湿毒浸淫（麻黄连翘赤小豆汤）、脾阳虚（实脾饮）、肾阳虚（真武汤）、瘀水互结（桃红四物+五苓）。
- **鉴别**：心/肝/肾源性水肿须西医排查；经行水肿、妊娠水肿另辨。
- **调护**：限盐、记录尿量体重、避劳累。

## 泄泻 · 痢疾
- **辨证要点**：泄泻辨寒湿/湿热/食滞/脾虚/肾虚；痢疾辨湿热（赤白脓血、里急后重）vs 寒湿 vs 阴虚痢 vs 虚寒痢。
- **证型（泄泻）**：寒湿（藿香正气）、湿热（葛根芩连汤）、食滞（保和丸）、脾虚（参苓白术散）、肾虚五更（四神丸）。
- **证型（痢疾）**：湿热（芍药汤）、疫毒（白头翁汤）、寒湿（胃苓汤）、阴虚（驻车丸）、虚寒（桃花汤）。
- **鉴别**：泄泻（无脓血）vs 痢疾（有脓血里急后重）；慢性腹泻查肠镜。
- **调护**：饮食卫生、忌生冷油腻、健脾为要。

## 黄疸
- **辨证要点**：**阳黄（湿热，黄色鲜明、尿黄、苔黄腻）vs 阴黄（寒湿，色暗如烟熏、畏寒、苔白腻）**；急黄（疫毒，色深危候）须急救。
- **证型**：阳黄热重（茵陈蒿汤）、湿重（茵陈五苓散）、胆腑郁热（大柴胡汤）；阴黄（茵陈术附汤）；急黄（犀角地黄汤+黄连解毒）。
- **鉴别**：溶血/肝细胞性/阻塞性黄疸西医分型必查；"钩虫黄""虚黄"另辨。
- **调护**：忌酒、低脂饮食、急性期卧床。

## 哮喘（哮证/喘证）
- **辨证要点**：**发作期宣肺化痰平喘（治标）；缓解期补肾纳气（治本）**。辨冷哮（痰稀白、畏寒）/热哮（痰黄稠、舌红）/虚哮。
- **证型（发作）**：冷哮（射干麻黄汤）、热哮（定喘汤）、风痰（三子养亲汤）。（缓解）肺虚（玉屏风）、脾虚（六君）、肾虚（肾气丸/七味都气丸）。
- **鉴别**：哮（有宿根、喉中哮鸣）vs 喘（气促未必哮）；心源性哮喘须排查。
- **兼夹变证**：久哮及心（喘脱危候）；缓解期扶正防复发是关键。
- **调护**：避过敏原、防寒、缓解期坚持扶正。

## 附：治未病思想（收藏价值最高的一条）
《内经》"上工治未病"：① 未病先防（调摄起居饮食情志、强身）；② 既病防变（早治防传变，如肝病先实脾）；③ 瘥后防复（病愈调护防复发）。这是中医最值钱的底层逻辑——**学中医不只为治病，更为会养生、知传变**。
