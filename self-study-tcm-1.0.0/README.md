# 自学中医阶梯（self-study-tcm）

> 把两本经典辅导读物《自学中医阶梯（一）（二）》整理成「能反复回来查的参考工具 + 分步陪学 + 可下载个人路线图」的中医自学陪学技能。
> 专治一句话：**"想学中医，但摸不着门径、读了就忘、不知下一步学什么。"**

---

## 一、它解决什么（为什么值得收藏）

学中医是**漫长且复杂**的事：从启蒙到经典到临床，动辄数年。痛点不是"没资料"，而是：

- **不知从哪本书读起**，常被《内经》硬骨头劝退 → 给"由浅入深、由约而博"的分阶段书单。
- **读经典抓不住重点** → 每部经典给"核心成就 + 具体善本 + 先读哪些篇章 + 常见误读"。
- **遇常见病想对照辨证思路** → "证型 → 治法 → 代表方"速查卡（备查，不诊断）。
- **学到哪算会、下一步去哪** → 六阶课程，每阶明确"学什么 / 学多深 / 学多久 / 怎么自测 / 完成标志 / 下一阶衔接"。
- **想要一份属于自己的、能存下来反复看的规划** → 生成《中医自学路线图》A4 HTML（可打印 PDF）。

> **关键设计（决定收藏量）**：中医诊断类技能常见"525 下载 / 0 收藏"——一次性讲完即走。
> 本技能反做：① **分步陪学**让人每次回来都拿到新的一步；② **辨证速查卡**随时回来翻；
> ③ **可下载路线图**存下来转发。复制已验证成功的"参考工具 + 交付物"范式。

## 三、怎么用（双模式）

### 模式 A：分步陪学（主模式，制造回访）
开口示例：「我想开始学」「我在第几阶」「给我下一步」。
→ 技能先问背景（古文基础？有无临床？目标方向？），据此定起点，**每次只给当前阶段**的任务、深度、自测；
用户完成自测后回来复盘，才推进下一阶。这是让人**收藏、反复打开**的核心钩子。

### 模式 B：一次性全景（交付物）
开口示例：「给我完整路线图」「生成我的规划」。
→ 调 `scripts/build_roadmap.py` 生成 A4 HTML，六阶全列 + 逐阶 checkpoint + 八法速记 + 常备参考卡，
可浏览器「打印 → 另存 PDF」存下来。

## 四、六阶总览（速读）

| 阶 | 主题 | 时长 | 出口标志 |
|---|---|---|---|
| 一 | 启蒙筑基 | 1–2 月 | 读懂四小经典、能背常用汤头 |
| 二 | 治学方法与治则 | 1 月 | 区分治则治法、说清标本 |
| 三 | 经典溯源 | 6–12 月 | 懂六经提纲、背 50 味上品 |
| 四 | 临床思维与辨证 | 3–6 月 | 症状→证型清单跑通 |
| 五 | 常见病专题 | 长期 | 每病 2–4 基本证型与通治方 |
| 六 | 跟师与临证 | 终身 | 真实病案串成辨证习惯 |

（每阶的完整"学多深 / 自测 / 书目 / 完成标志 / 下一阶"见 `learning-progression.md` 或生成路线图。）

## 五、样例交付物

`sample-roadmap.html` 是用 `scripts/build_roadmap.py` 生成的示例路线图（零基础背景），
打开即可看到交付物长什么样——A4 排版、六阶 checkpoint、可打印存 PDF。

生成你自己的：
```bash
cd scripts
python build_roadmap.py --background zero --clinical no --goal entry --name 你的名字 --out ../my-roadmap.html
# background: zero(零基础) | classical(有古文) | clinical(有临床)
# goal: entry(入门) | classic(经典) | clinic(临床) | exam(应试) | interest(兴趣养生)
```

## 六、常见问题（FAQ）

- **Q：零基础真的能自学吗？** 能，但必须"由浅入深"——先四小经典启蒙，别硬啃《内经》。本技能第 1–2 阶就是为你设计的。
- **Q：多久能"学完"？** 中医无速成。前 3 阶打基础约 1–2 年，第 4–5 阶临床思维长期积累，第 6 阶终身跟师。路线图按阶段给时长参考。
- **Q：能照着方子自己吃药吗？** **绝对不能。** 速查卡仅供理解思路、辅助学习；古籍方剂严禁自服，身体不适务必就医（见 `disclaimer.md`）。
- **Q：和"中医诊断思维"类技能有什么区别？** 那类是"讲一遍就走"的静态参考；本技能是"分步陪学 + 可下载路线图"，让你反复回来、循序渐进。
