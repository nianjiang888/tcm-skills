# 自学中医阶梯

一个面向「想自学中医、但摸不着门径」的人的陪学技能。它把两本经典辅导读物
《自学中医阶梯（一）（二）》的精华，整理成**可反复回来查的参考体系 + 可下载
的个人学习路线图**，帮助自学者少走弯路、按正确顺序入门并提高。

## 这个技能解决什么

- 初学者不知从哪本书读起、常被经典「硬骨头」劝退 → 给出「由浅入深、由约而博」的分阶段书单。
- 读经典抓不住重点 → 每部经典给「核心成就 + 入门善本 + 学习顺序」。
- 遇到常见病想对照辨证思路 → 提供「证型 → 治法 → 代表方」速查卡（备查，不诊断）。
- 想要一份属于自己的、能存下来反复看的规划 → 生成《中医自学路线图》HTML/PDF。

## 怎么用（交互方式）

本技能用**双模式**对抗"看完就走"：主模式是**分步陪学**（每次只给当前阶段，制造回访理由）；次模式是**一次性全景**（生成可保存路线图）。

用户通常这样开口，路由到对应模块：

| 用户意图 | 路由 |
|---|---|
| 「我想开始学」「我在第几阶」「给我下一步」 | `learning-progression.md` —— **分步陪学主引擎**：六阶课程，每次只给一阶任务/深度/自测 |
| 「我零基础，中医怎么入门？」「推荐学习顺序」 | `study-path.md` —— 治学之道 + 按背景出分阶段书单 |
| 「伤寒论/金匮/内经该先读哪本？怎么读？」 | `classics.md` —— 六部经典导读（善本/篇章/误读） |
| 「汗法/下法/八法是什么？治则有哪些？」 | `principles-methods.md` —— 治则八条 + 医门八法（含误治） |
| 「感冒/咳嗽/胃痛怎么辨证？用什么方？」 | `syndrome-reference.md` —— 常见病辨证速查（收藏主区） |
| 「给我完整路线图」「生成我的规划」 | 调 `scripts/build_roadmap.py` 出 A4 HTML 报告 |

## 判定 / 路由逻辑（三条要点）

1. **由浅入深，不从难入手**：古汉语/文史底子薄的人，硬啃《内经》多半事倍功半；
   应先从《药性赋》《汤头歌诀》《医学三字经》启蒙，再溯源经典。
2. **治则优先于记方**：先懂「整体调治、治病求本、标本缓急」，方子才能活用；
   死记汤头而不明理法，遇变证必乱。
3. **知常达变**：常见病先掌握基本证型与通治方（是「常」），再学兼夹、变证（是「变」）。
   本技能所有速查表只列「常」，复杂个案请遵医嘱。

## 交付物

`scripts/build_roadmap.py` 根据用户背景（古文基础 / 有无临床 / 目标方向）生成
《中医自学路线图》：含六阶总览、逐阶 checkpoint（任务/深度/自测/书目/完成标志）、
八法速记、常备参考卡，输出 A4 HTML（可浏览器「打印→另存 PDF」）。
这是本技能「让人收藏、反复回来查」的核心载体。

## 内置知识库

本技能**自带离线知识库**（package 内 .md 即知识库，无联网依赖），内容源自用户上传的两本
IMA 知识库 PDF（《自学中医阶梯（一）（二）》，邓铁涛、姜春华等 24 位编委）及公认善本导读，
全部从原书抽取、未编造。若需 RAG 检索更细原文，可把那两本 PDF 作为 IMA 知识库挂载。
