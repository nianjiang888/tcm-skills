# 免责声明与使用边界

## 本技能的性质
「自学中医阶梯」是**中医自学辅导与教育参考**工具，内容整理自《自学中医阶梯（一）（二）》
等公开辅导读物，目的是帮助自学者建立学习路径、理解辨证思路，**不是诊疗工具**。

## 明确边界
1. **不提供诊断**：本技能不做、也不能替代任何疾病的诊断。
2. **不提供治疗方案**：所有「证型 → 治法 → 代表方」速查仅用于理解中医学术思路、
   辅助学习，不构成对任何个体的用药或治疗建议。
3. **不替代执业医师**：身体不适、用药、针灸、急救等，务必前往正规医疗机构，
   由持证执业医师面诊处理。
4. **古籍方剂的现代适用性**：书中方剂为历史文献，剂量、炮制、禁忌与现代临床不同，
   **严禁自行照方抓药服食**。
5. **特殊人群**：孕妇、儿童、老人、慢性病及危重症患者，任何自我处理都极其危险，必须就医。

## 内容准确性
医学知识持续更新，本技能整理内容以原辅导读物为准，可能存在时代局限；
如与原著或现行规范冲突，以权威教材、法规及执业医师意见为准。

## 使用建议
把它当作「陪你入门、帮你查框架」的参考书与路线图生成器，
真正临床能力来自系统学习 + 跟师临证 + 合法资质。自学需要良师益友，而非自行试药。
