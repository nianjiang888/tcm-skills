# 治学之道与学习路径

摘自《自学中医阶梯（一）》第一部分「治学之道」，并结合全书的入门主张整理。
核心一句话：**入门并不难，深造也办得到，关键是立志坚韧、自学得法。**

## 一、五勤（治学的艺术）

| 字 | 做法 | 要点 |
|---|---|---|
| 勤读 | 反复阅读、把书读熟 | 早下手背书；经典熟读成诵，临证才成「有源头的活水」 |
| 勤思 | 读书贵在精思 | 「学而不思则罔」；心到最急，熟读精思理自知 |
| 勤问 | 自问自答 + 拜能者为师 | 大疑则大进；程门立雪、叶天士拜十七师，皆诚心求教 |
| 勤写 | 写笔记、写心得、写病历 | 资料贵在一线穿；死资料变活材料 |
| 勤习 | 读书临证相得益彰 | 熟读王叔和不如临证多；知常达变从实践来 |

## 二、两条读书总纲

- **由约而博，由博返约**：先深钻一两部「得力」之作（如《伤寒来苏集》《医学心悟》），
  终身受用，再广泛涉猎，才不会茫无头绪、「读书死」。
- **由浅入深，深入浅出**：古汉语底子薄的人，**不要先啃《内经》**。从《药性赋》
  《汤头歌诀》《医学三字经》启蒙，兴趣油然而生，再溯源经典。

> 反例：赵金铎依祖父「先熟读内经」死读，百思不解；改读《古今医鉴》《陈修园七十二种》
> 等通俗书，耳目一新。说明**从易入手也是正门**。

## 三、读书抓特色

不可能记住每本书所有内容，要「提纲挈领」。例：陈修园把金元四大家归纳为
「李东垣重脾胃升清气、张子和主攻破、刘河间专主火、朱丹溪阴宜补阳勿浮」，
言简意赅即抓住特色。

## 四、分阶段学习路径（按背景）

### 路径 A：零基础 / 古文弱
1. 启蒙通俗读物：《药性赋》《汤头歌诀》《医学三字经》（「四小经典」）
2. 通俗临床：《医学心悟》（程钟龄，深入浅出，屡印不衰）
3. 系统教材：统编《中医学基础》打底
4. 溯源经典：《伤寒论》白文 + 善本（如《伤寒来苏集》《伤寒贯珠集》）→《金匮要略》→《内经》
5. 各家学说与现代著述

### 路径 B：有古文 / 文史底子
1. 可直接从《伤寒论》入手（文字朴实、承上启下），配合善本注本
2. 上溯《内经》、博采众方，下循各家
3. 重点攻一家（如脾胃学说、温病学说）形成专长

### 路径 C：有临床体验、想系统提高
1. 以治疗学为纲：先《医学心悟》的「医门八法」
2. 补经典短板：伤寒 / 金匮 / 内经 择要精读
3. 按科深入：参 `syndrome-reference.md` 的临床各科辨证

## 五、资料与病历

- **资料一线穿**：随手记卡片（作者/题目/提要/出处），再把有关资料对比综合、形成自己的新观念，写成文献综述，死资料变活材料。
- **写好中医病历**：从淳于意「诊籍」到喻嘉言「议病式」，病历是总结临证经验的基本功；
  格式含一般记录、发病治疗经过、现症、辨证分析、诊断、治法、方药、疗效预测。
