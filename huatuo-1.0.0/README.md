## 1. 这是什么
把《百酒/百粥/百汤/百姓治百病》四本书的民间验方，做成「神医华佗」人格的、**会主动问诊的 Agent**。
你脑子里冒出「感冒了怎么办」「咳嗽吃什么」「血压高怎么调」「失眠怎么调理」，华佗就给你对症的调理方。
不是被动文档，而是带真实逻辑的检索引擎 + 安全分级（绿/黄）+ 急症红标。

民间疗法矩阵「老偏方」系列的**人格化入口**：3 套中医理论 + 4 套民间食疗效法 → 现在多一个「望闻问切」的智能顾问。

## 2. 参照打法（学谁 / 模仿什么）
- **学谁**：对标「智慧半岛 / 天工.开物」的李白·钟馗·鲁班——文化原型人格宇宙，人物即功能，能口语唤起。
- **模仿三件事**：
  1. 人格即功能：华佗=神医→望闻问切的养生顾问，用户会自然说「华佗帮我看看」。
  2. **主动干活（带真实逻辑，不是文档）**：`scripts/huatuo_engine.py` 内置急症检测 + 症状归类 + 验方检索 + 安全分级。
  3. 描述堆触发词 + 快迭代：SKILL.md description 覆盖「感冒了怎么办/失眠怎么调理/血压高怎么降…」等口语，按下载反馈持续调。

## 3. 怎么用（路由表）
| 用户意图 | 路由 |
|---|---|
| 描述具体症状（感冒/咳嗽/失眠/胃痛/头痛/血压高/鼻炎/腹泻/牙痛…） | `scripts/huatuo_engine.py "<症状>"` → 华佗转述 |
| 想看全部验方清单 | `huatuo-cards.md` / `resources/remedies.json` |
| 病证归类与中医基础 | `huatuo-theory.md` |
| 想系统学中医食疗/一步步来 | `learning-progression.md` |
| 生成我的个人速查手册（A4 可打印） | `scripts/build_huatuo_handbook.py` |

## 4. 主动问诊决策图
```
症状输入 ──→ 急症红标？(胸痛/呼吸困难/大出血/中风/昏迷…)
                ├─ 是 → 强制就医卡（禁止给药方）
                └─ 否 → 归病证（风寒/风热/肠胃/失眠/三高/头痛…）
                         → 引擎检索 resources/remedies.json（339 条）
                         → 绿/黄分级 + 「遵医嘱」红线 → 华佗口吻转述
```

## 5. 内置资产（离线）
- `scripts/huatuo_engine.py` —— 主动问诊引擎（真实可执行逻辑）

- `huatuo-cards.md` —— 339 条验方的人类可读速查卡
- `huatuo-theory.md` —— 症状→病证归类 + 中医基础 + 用法红线
- `learning-progression.md` —— 六阶陪学
- `disclaimer.md` —— 教育参考非诊疗、民间方剂严禁自服
- `scripts/build_huatuo_handbook.py` —— A * A4 手册生成器（--name/--use/--out）

## 6. 交付物
`scripts/build_huatuo_handbook.py` 按 `--name`(姓名) 与 `--use`(用途) 生成
《华佗养生速查手册》A4 HTML（病证检索树 + 全部验方卡 + 六阶路线 + 个人勾选框），浏览器打印即 PDF。

## 7. 边界
本技能是民间疗法检索与自学辅导工具，不是诊疗工具，不替代执业医师。所有配方仅供理解思路、辅助养生，
身体不适务必就医。详见 `disclaimer.md`。
