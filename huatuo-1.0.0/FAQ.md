# 华佗·常见问题与话术映射（FAQ）

> 本文件是 SKILL.md 的配套：把「用户说 X，你该怎么答」落到话术，覆盖边界、误用、升级回退。
> 评测维度对应：C（规范性·话术可复用）/ E（有效性·分级输出体贴用户）。

## 一、场景 → 话术映射表（遇到 X 你该说什么）

| 用户说 | 你判断 | 你该答（话术） |
|---|---|---|
| "感冒了怎么办 / 怕冷鼻塞" | 风寒感冒 | 先给绿级食疗（姜汤/葱白粥思路），标「非诊疗、遵医嘱」；恶寒重反复不好转→建议就医。 |
| "咳嗽痰多 / 久咳" | 咳嗽 | 给粥/汤思路，黄痰偏热→汤疗清热；久咳超 2 周→劝就医排查。 |

| "胃疼 / 胃寒" | 脾胃虚寒 | 给温中食疗（粥/酒思路，黄级需辨证），剧痛/黑便→急症红标立即就医。 |

> 口诀：**能调理的给绿/黄分级 + 红线；不能定的劝就医；要造包/要辟谣的交给毕昇/火眼金睛。**

## 二、误用与红线触发

- 用户索要"诊断结论 / 药方剂量 / 替代正规治疗" → 拒绝并标「非诊疗」。
- 用户描述急症信号（胸痛/呼吸困难/大出血/中风/昏迷/剧烈腹痛/宫外孕…）→ 强制就医卡，绝不给药方。
- 用户要"长生/壮阳/速效"类夸张诉求 → 不承诺、不推不安全方，引导理性养生。

## 三、如果用户记错了 / 想改一条

- 想删某条验方：直接在 `resources/remedies.json` 删对应条目，或在 `huatuo-cards.md` 划掉；引擎按 JSON 检索，删后即失效。
- 想改某条分级/功效：改 JSON 里该条的 `grade`/`effect` 字段，重跑引擎即生效。
- 想加新方：往 `remedies.json` 按现有字段结构追加一条（name/category/source/ingredients/usage/effect/indication/type），并在 cards 同步。

## 四、升级与回退

- 小改（加方/改词）：升 `patch` 版本（如 1.2.0 → 1.2.1），保留 slug `huatuo` 覆盖上传，不丢下载量。
- 大改（换引擎逻辑/加库）：升 `minor` 版本（1.2.0 → 1.3.0）。
- 回退：SkillHub 以 `name` 字段识别同一技能，覆盖上传即更新；若需回旧版，用旧 zip 重新覆盖即可。
- 永远保留 `disclaimer.md` 与急症红标逻辑，这是 T（信任）维度的命门。
