# 华佗六阶陪学（learning-progression.md）

> 想系统学中医食疗，一轮一轮过。每阶给「学什么 / 学多深 / 自测 / 完成标志 / 误区」。

## 一阶 · 认门道（入门）
- **学什么**：八纲（寒热虚实表里阴阳）、食疗「寒者热之、热者寒之」。
- **学多深**：能区分风寒/风热、体质寒热。
- **自测**：说出风寒与风热的差别。
- **完成标志**：看到症状能初步归类。
- **误区**：把「补」当万能、不分体质乱吃。

## 二阶 · 识四库（基础）
- **学什么**：药酒/粥疗/汤疗/民间综合四类用法与禁忌。
- **学多深**：知道各自适用场景与红线。
- **自测**：什么情况选粥、什么选酒。
- **完成标志**：能按病证选库。
- **误区**：急性症依赖食疗、忽略过敏。

## 三阶 · 会查方（进阶）
- **学什么**：`huatuo-cards.md` 高频病证卡的检索。
- **学多深**：感冒/咳嗽/失眠/胃病都能查到方。
- **自测**：现场查 3 个常见病。
- **完成标志**：脱离提示自主查方。

## 四阶 · 辨体质（进阶）
- **学什么**：虚实体质、兼夹证、特殊人群红线。
- **学多深**：孕/童/慢病一律「遵医嘱」。
- **自测**：指出哪些是绝对就医情形。
- **完成标志**：能识别急症与禁忌。

## 五阶 · 做手册（产出）
- **学什么**：`scripts/build_huatuo_handbook.py` 生成个人 A4 手册。
- **学多深**：能定制姓名/用途并导出。
- **完成标志**：拿到自己的速查手册。

## 六阶 · 会判断（精通）
- **学什么**：把「养生」当长期习惯，不替代就医。
- **学多深**：能向家人解释「为何要遵医嘱」。
- **完成标志**：成为家庭养生顾问。
- **误区**：自以为懂医、擅自停药。
