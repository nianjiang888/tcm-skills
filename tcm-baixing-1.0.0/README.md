# 百姓治百病民间验方速查 · 使用说明（README）

> 技能包：`tcm-baixing` ｜ 底本：《百姓治百病》（王慧芬 主编 · 上海远东出版社 2003）｜ 版本：1.0.0

## 一、这个技能是干什么的
把《百姓治百病》变成**「带着小毛病来查」的民间疗法速查工具**。你问"感冒喝什么民间验方、咳嗽吃什么、血压高有什么偏方"，它从原书真实验方里给你对症的配方与制法。

## 二、它解决什么痛点
- 民间书"看完就走"：本书 800+ 方/数百条，普通人记不住。**本技能把它们拆成可勾选的检索树 + 可打印的个人手册**，让人反复回来查、收藏、转发。
- 与理论层三套（self-study-tcm / tcm-syndrome-lookup / tcm-wenda）互补，构成「理论 → 民间疗法」完整矩阵；四本百X书本身又形成群众向子矩阵。

## 三、内容范围
按主题篇归类：健康序篇 / 食疗 / 外治 / 按摩推拿 / 运动 / 减肥 / 修身康性 / 健身须知，数百条民间方与自我保健法。

## 四、怎么用（两种模式）
1. **分步陪学（主）**：每次只给当前一阶，自测过了再推进——`learning-progression.md` 把"民间食疗怎么入门、学到多深"拆成六阶。
2. **一次性全景（A4 交付物）**：调 `scripts/build_baixing_handbook.py` 生成《百姓治百病民间验方手册》，可存可转发可打印。

## 五、文件清单
| 文件 | 作用 |
|---|---|
| `SKILL.md` | 技能入口、触发词、路由表 |

## 六、怎么生成我的手册
```bash
cd scripts
python build_baixing_handbook.py --name 张三 --use 家庭养生 --out ../my-handbook.html
```
浏览器打开 `my-handbook.html` → 打印 → 另存 PDF。

## 七、重要提醒
本技能**不是诊疗工具**，所有配方来自民间食疗/验方科普，**仅供养生参考**。孕妇、慢病、服药者、儿童用前务必咨询医生；急症、重病直接就医。详见 `disclaimer.md`。
