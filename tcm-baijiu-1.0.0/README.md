# 百酒治百病验方速查 · 使用说明（README）

> 技能包：`tcm-baijiu` ｜ 底本：《百酒治百病》（蒋建栋 主编 · 中国时代经济出版社 2002.1）｜ 版本：1.0.0

## 一、这个技能是干什么的
把《百酒治百病》变成**「带着小毛病来查」的民间疗法速查工具**。你问"感冒喝什么药酒、咳嗽吃什么、血压高有什么偏方"，它从原书真实验方里给你对症的配方与制法。

## 二、它解决什么痛点
- 民间书"看完就走"：本书 800+ 方/数百条，普通人记不住。**本技能把它们拆成可勾选的检索树 + 可打印的个人手册**，让人反复回来查、收藏、转发。
- 与理论层三套（self-study-tcm / tcm-syndrome-lookup / tcm-wenda）互补，构成「理论 → 民间疗法」完整矩阵；四本百X书本身又形成群众向子矩阵。

## 三、内容范围
以病为纲、以方为目：内科/妇科/儿科/外科/皮肤科/五官科……数百病证，每病数方至数十方。

## 四、怎么用（两种模式）
1. **分步陪学（主）**：每次只给当前一阶，自测过了再推进——`learning-progression.md` 把"民间食疗怎么入门、学到多深"拆成六阶。
2. **一次性全景（A4 交付物）**：调 `scripts/build_baijiu_handbook.py` 生成《百酒治百病验方手册》，可存可转发可打印。

## 六、怎么生成我的手册
```bash
cd scripts
python build_baijiu_handbook.py --name 张三 --use 家庭养生 --out ../my-handbook.html
```
浏览器打开 `my-handbook.html` → 打印 → 另存 PDF。

## 七、重要提醒
本技能**不是诊疗工具**，所有配方来自民间食疗/验方科普，**仅供养生参考**。孕妇、慢病、服药者、儿童用前务必咨询医生；急症、重病直接就医。详见 `disclaimer.md`。
