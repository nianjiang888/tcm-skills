# 百酒治百病验方速查（tcm-baijiu）

## 解决什么

把《百酒治百病》（蒋建栋 主编，中国时代经济出版社 2002.1，ISBN 7-80169-093-1，CIP R247.1（药酒-食物疗法））整理成**「带着小毛病来查」的民间疗法速查工具**——你脑子里冒出"感冒喝什么酒""风寒咳嗽吃什么""血压高有什么偏方"，就来解决。

带着小毛病来查一道药酒验方——蒋建栋《百酒治百病》800余药酒方的随身速查工具。（民间疗法矩阵「老偏方」系列之一）

本技能与矩阵内另三套<b>群众向民间疗法</b>互补（四本百X书形成矩阵）：
- `tcm-baijiu`（百酒治百病）= **药酒**验方速查
- `tcm-baizhou`（百粥治百病）= **粥疗**验方速查
- `tcm-baitang`（百汤治百病）= **汤疗**验方速查
- `tcm-baixing`（百姓治百病）= **民间综合**验方/保健法速查

同时也与理论层三套（self-study-tcm / tcm-syndrome-lookup / tcm-wenda）形成「理论 → 民间疗法」完整矩阵。

## 判定 / 路由逻辑（三条要点）

1. **先定位"落在哪一类"**：药酒/粥/汤按病证归类；百姓按"主题篇"归类。先定类再深挖，避免答非所问。
2. **只列"方"，不替"医"做主**：速查卡只给用料/制用法/功效/适应症（常），复杂体质、兼夹证、特殊人群一律提示「遵医嘱」，不擅自给诊疗结论。
3. **速查体即检索体**：用户"带着小毛病来"的句式与书中"以病为纲、以方为目"天然一致，直接用卡片作答，比长篇讲义更易收藏复用。
